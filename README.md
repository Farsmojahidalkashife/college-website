# مشروع موقع كلية العلوم الرياضية والحاسوب - جامعة الجزيرة

هذا المشروع هو عمل أكاديمي لتطوير موقع تعريفي لكلية العلوم الرياضية والحاسوب بجامعة الجزيرة. تم بناء الموقع على مراحل تدريجية وفقاً لمتطلبات المقرر الدراسي.

## مراحل المشروع

- **المرحلة الأولى (HTML):** تم إنجازها. تشمل بناء الهيكل الأساسي للصفحات باستخدام وسوم HTML5 الدلالية (Semantic Tags) بدون أي تنسيقات بصرية.
- **المرحلة الثانية (CSS):** تم إنجازها. تشمل إضافة التصميم البصري، الألوان، الخطوط، التفاعلات، والتجاوب مع شاشات الجوال.
- **المراحل القادمة:** سيتم إضافة لغة JavaScript (للتفاعلات الديناميكية) ثم PHP (لربط الموقع بقاعدة البيانات) في المراحل اللاحقة.

## محتويات المشروع

- الصفحات الرئيسية: `index.html` (الرئيسية)، `about.html` (عن الكلية)، `contact.html` (التواصل)، `terms.html` (الشروط والأحكام).
- مجلد `majors`: يحتوي على 4 صفحات منفصلة للتخصصات الأكاديمية.
- مجلد `account`: يحتوي على صفحتي تسجيل الدخول وإنشاء حساب.
- مجلد `assets`: يحتوي على الموارد الأساسية للموقع:
  - `css/`: ملفات التصميم (مقسمة إلى `base` و`layout` و`components`).
  - `fonts/`: الخطوط العربية المحلية (Cairo وTajawal).
  - `images/`: الشعار وصور الكلية.

## ملاحظات تقنية عن التصميم (CSS)

1. **الهوية البصرية:** تم استخراج الألوان (الأزرق الداكن والذهبي) من شعار الكلية واعتمادها كألوان أساسية للموقع.
2. **المتغيرات:** تم استخدام متغيرات CSS (`:root`) في أعلى ملف التصميم، لتسهيل تعديل ألوان الموقع مستقبلاً من مكان واحد فقط.
3. **التنظيم:** تم تقسيم أكواد CSS إلى 3 ملفات لسهولة الصيانة والقراءة.
4. **التجاوب (Responsive):** الموقع مصمم ليتكيف مع شاشات الجوال (عند عرض 768px فأقل) باستخدام Flexbox وGrid وMedia Queries بسيطة.
5. **التفاعلات:** تم إضافة تأثيرات بسيطة عند تمرير الماوس (Hover) على الأزرار والروابط لإعطاء تجربة مستخدم أفضل.
